# 思齐 StudySage · AI 学习辅助智能体

> 「见贤思齐焉，见不贤而内自省也。」——《论语·里仁》
>
> 思齐是一款覆盖**学生端与教师端双视角**的 AI 学习辅助智能体。它不直接喂答案，而是引导学生自己推导、诊断真实掌握度、检测复述偏差、归因错误，并把全班学情沉淀为可行动的教学看板。
>
> **零依赖、零构建**：默认纯离线即可完整演示全部核心流程；AI 能力由内置规则/模拟推理引擎实现，并在统一接口层支持**一键接入你自己的 OpenAI 兼容 API**——配置后即可解锁**全网知识点搜索**等真实大模型能力，业务代码无需任何改动。

---

## 一、痛点分析

学习与教学场景中，工具普遍存在以下真实痛点：

| # | 痛点 | 具体表现 |
|---|------|----------|
| P1 | **搜题即得答案，思维被替代** | 学生拍照/提问后直接拿到完整解答，抄完即止，缺乏独立思考，同类题反复错。 |
| P2 | **分数≠掌握度，学情是黑箱** | 只知道考了多少分，不知道具体哪个知识点薄弱、该先补什么，盲目刷题。 |
| P3 | **「看懂了」是错觉** | 学生以为听懂看懂，合上书却讲不出来，理解偏差无法被及时暴露。 |
| P4 | **错题本只收藏不归因** | 错题越攒越多，只记录题目，不区分错误原因，无法针对性改进。 |
| P5 | **教师缺乏精准学情抓手** | 一个班几十人，老师难以掌握每个学生的薄弱点和班级共性错误，讲评只能凭经验、平均用力。 |
| P6 | **学完就忘，复习无节奏** | 没有科学的复习安排，考前突击，知识无法进入长期记忆。 |

## 二、创新点 ↔ 痛点 ↔ 实现 对应关系

每个创新点都对应真实痛点，且在代码中有**真实可演示的交互逻辑**，而非静态摆设。

| 创新点 | 解决痛点 | 实现文件 | 真实交互逻辑 |
|--------|----------|----------|--------------|
| **1. 苏格拉底式引导答疑** | P1 | `src/engine/socraticEngine.js`、`src/ui/student/tutorView.js` | 学生提问后先判断题型（概念题/计算题/应用题），不直接给答案，而是抛出引导性问题；学生卡住（「不知道/提示」）或答错时，按 **3 级分层提示**逐级释放；连续卡住达到阈值（`MAX_WRONG_BEFORE_REVEAL`）或学生主动点击「查看完整解答」后，才给出完整解答。答对且未依赖提示记为「首试掌握」，借助提示答对记为「引导后掌握」。 |
| **2. 掌握度诊断与个性化路径** | P2 | `src/engine/diagnosisEngine.js`、`src/data/knowledgeMap.js`、`src/ui/student/masteryView.js` | 依据答题/对话记录，按知识点计算加权掌握分并标记 **未学 / 薄弱 / 掌握** 三态；结合知识点的**先修依赖关系**（有向无环图）自动排序，生成带诊断、建议、预计耗时的个性化补漏路径，每步可一键跳转专项练习。 |
| **3. 费曼复述检测** | P3 | `src/engine/feynmanEngine.js`、`src/ui/student/feynmanView.js` | 学生用自己的话复述知识点，引擎基于关键词覆盖度打分，列出**已覆盖/遗漏的关键概念**，并通过内置「误解模式库」识别**理解偏差**（如把「负负得正」讲反），给出纠正与改进建议。 |
| **4. 错题归因** | P4 | `src/engine/mistakeEngine.js`、`src/ui/student/mistakesView.js` | 错题不止收藏：选择题依据干扰项映射自动归因，填空题依据常见错答模式识别；系统无法识别时，要求学生**自我归因**。五类原因（概念误解/审题失误/计算错误/方法步骤缺失/粗心笔误）可筛选、统计，并可标记掌握、跟踪解决率。 |
| **5. 教师端学情看板** | P5 | `src/ui/teacher/dashboardView.js`、`src/ui/charts.js`、`src/data/seedStudents.js` | 汇总 10 名内置学生 + 本机学生的全部数据，渲染薄弱知识点分布柱状图、错误类型环形图、薄弱点排行、**学生×知识点掌握度热力矩阵**，并自动生成可执行的精准教学建议；支持按学生/全班切换查看范围。 |
| **6. 遗忘曲线间隔复习** | P6 | `src/engine/reviewScheduler.js`、`src/ui/student/reviewView.js` | 每次学习后自动按间隔序列 **1→2→4→7→15→30 天**安排复习；到期复习时「记得通过」则推进到下一间隔，「想不起来」则重置间隔；完成全部间隔进入长期记忆。提供「模拟到期」按钮便于演示。 |
| **7. 全网知识点搜索** | — | `src/engine/searchEngine.js`、`src/ui/student/searchView.js`、`src/engine/llmAdapter.js` | 突破内置题库边界：学生输入任意学科关键词（如勾股定理、光合作用），本地模式检索内置知识图谱；**接入自己的 API 后切换远程模式**，大模型扮演知识百科检索引擎，返回结构化知识卡片（定义/关键概念/常见误解/相关知识/典型例子），命中内置知识点可一键跳转引导答疑或费曼复述；支持热门搜索与搜索历史。 |

## 三、功能架构

```
StudySage
├── index.html                 # 单页应用入口（hash 路由）
├── server.js                  # 零依赖 Node 静态服务器（内置 http 模块）
├── package.json
├── styles/main.css            # 全部样式
└── src
    ├── main.js                # 应用入口、路由、角色切换
    ├── data
    │   ├── knowledgeMap.js    # 6 个知识点 + 先修依赖关系（DAG）
    │   ├── questionBank.js    # 14 道题：分层提示/解答/干扰项归因/错答模式
    │   └── seedStudents.js   # 10 个 mock 学生（确定性种子生成作答记录）
    ├── engine
    │   ├── llmAdapter.js      # 统一 AI 接口层：本地规则引擎 / 远程大模型（含连接测试、JSON 结构化输出）
    │   ├── socraticEngine.js  # 苏格拉底引导状态机
    │   ├── diagnosisEngine.js # 掌握度诊断 + 个性化路径
    │   ├── feynmanEngine.js   # 费曼复述检测
    │   ├── mistakeEngine.js   # 错题归因
    │   ├── reviewScheduler.js # 遗忘曲线间隔复习
    │   ├── searchEngine.js    # 全网知识搜索（本地图谱检索 / 远程大模型检索）
    │   └── registerEngines.js # 向 llmAdapter 注册本地规则处理器
    ├── store/storage.js       # localStorage 持久化封装
    ├── ui
    │   ├── charts.js          # 纯手写 SVG 图表（柱状/环形/热力/排行）
    │   ├── appShell.js        # 应用外壳与导航
    │   ├── student            # 学生端 7 个视图（含全网知识搜索）
    │   └── teacher            # 教师端看板与引擎设置
    └── utils/helpers.js       # 工具函数
```

### 技术选型

- **零依赖原生 ES Module**：无 npm install、无打包构建，浏览器直接加载，避免任何环境/网络问题。
- **数据全部本地存储**：`localStorage`（键 `studysage_state_v1`），刷新不丢失；提供「重置演示数据」一键还原。
- **AI 双层架构**：所有智能能力都通过 `llmAdapter.complete(task, input)` 调用。
  - 本地模式（默认）：命中已注册的规则处理器，纯状态机/关键词/确定性算法实现，完全离线。
  - 远程模式：按 OpenAI Chat Completions 兼容协议请求**你自己配置的大模型 API**，支持一键连接测试、超时控制、结构化 JSON 输出与友好错误提示；配置后业务代码与数据结构无需改动。
  - 已注册任务：`socratic`、`feynman`、`diagnosis`、`mistake`、`review`、`search`（全网知识搜索）。

## 四、运行方式

### 方式一：Node 静态服务器（推荐）

```bash
cd StudySage
node server.js
# 或
npm start
```

默认监听 `http://127.0.0.1:8090`，可用环境变量覆盖：

```bash
HOST=0.0.0.0 PORT=3000 node server.js
```

### 方式二：任意静态服务器

```bash
# Python
python3 -m http.server 8090
# 或直接用浏览器打开 index.html（file:// 亦可，ES Module 建议走 http）
```

打开浏览器访问对应地址即可。**无需任何 API Key 或联网。**

## 五、演示流程

### 学生端（左下角「学生端」）

1. **全网知识搜索**：在搜索框输入任意知识点（如「惯性」「勾股定理」）→ 本地模式检索内置知识图谱；教师端「引擎设置」中填入自己的 API 并切换远程模式后 → 搜索「光合作用」「电磁感应」等任意学科知识点，观察结构化知识卡片（定义/关键概念/常见误解/相关知识/典型例子），点相关知识标签可连续检索。
2. **引导式答疑**：左侧任选一题 → 输入「不知道/提示」观察逐级释放的 3 层提示 → 中途答错观察引导 → 最终输入正确答案（如第一题 `-8`）获得鼓励；也可点「查看完整解答」直接看完整解析。
3. **答题/自测**：逐题作答。故意选错（如第一题选 B）观察**自动归因**；填空题输入未预置的错答（如第三题填 `5`）观察**自我归因**按钮。
4. **掌握度与路径**：查看知识点掌握状态（未学/薄弱/掌握）、掌握分，以及按先修依赖排序的个性化补漏路径，点「去练习」跳转。
5. **错题本**：按错误原因筛选、下拉修改归因、点「标记已掌握」观察解决率变化。
6. **费曼复述**：选择知识点，用自己的话讲解（可故意讲错，如「两个负数相乘得到负数」），提交后观察覆盖度、遗漏概念与理解偏差提示。
7. **间隔复习**：点「模拟到期」让复习提前到期 → 「记得，通过」推进间隔（1→2 天），「想不起来」则重置。

### 教师端（左下角「教师端」）

1. **学情看板**：查看班级 KPI（人数/作答数/正确率/薄弱点数）、薄弱知识点分布柱状图、错误类型环形图、薄弱点排行、学生×知识点热力矩阵，以及自动生成的精准教学建议；用「查看范围」下拉在全班与单个学生间切换。
2. **引擎设置**：切换本地规则引擎/远程大模型；在远程模式下填入自己的 API 地址、Key、模型名称 → 点「测试连接」验证连通性 → 成功后即可在学生端「全网知识搜索」中使用真实大模型检索全网知识点。

## 六、数据与可扩展性说明

- 内置 6 个知识点（数学：有理数符号运算、一元一次方程解法/应用题；物理：牛顿第一定律、惯性、二力平衡）与 14 道题，先修关系构成有向无环图。
- 10 个 mock 学生使用确定性随机种子（mulberry32, seed=20261105）生成，保证每次演示数据一致、可复现。
- 扩展题库/知识点只需在 `src/data/` 中按现有结构追加；接入真实大模型只需在「引擎设置」中切换远程模式、填入兼容 OpenAI 协议的端点与 Key 并测试连接，即可驱动全网知识搜索与各引擎的真实推理，或在 `llmAdapter.js` 中扩展自定义适配器。
